# Storefront Imagery Handoff

The public storefront currently uses optimized Unsplash photography so the landing-page slice can
ship while the ImageGen account is unavailable. The consuming module is
`apps/web/src/features/storefront/storefront-media.ts`; replace the URLs there without changing
the section components or their layout contracts.

## Swap checklist

1. Generate one final image per row using the prompt above and save the selected files under
   `apps/web/public/images/storefront/`.
2. Update only the matching `desktop`, `mobile`, or `src` value in `storefront-media.ts` to a
   root-relative path such as `/images/storefront/hero.webp`.
3. Preserve the existing `alt` text and verify the hero crop at 390 px and 1440 px widths.
4. Run `pnpm --filter @carbon/web build` and the storefront Playwright checks before deployment.
